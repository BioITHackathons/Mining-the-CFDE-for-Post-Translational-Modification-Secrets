About This Tool

Queries the GlyGen REST API in real time to retrieve glycosylation sites, phosphorylation sites, SNVs, disease associations, and PTM annotations for any human protein. Focused on neurodegenerative disease proteins but works for any protein in GlyGen.

Data sources include UniProtKB, iPTMnet, BioMuta, UniCarbKB, PubMed, and more.

Search for a protein to explore its PTMs

Enter a UniProt accession (e.g. P05067) or click one of the preset neurodegenerative disease proteins in the sidebar. The tool will query GlyGen's live API and show glycosylation, phosphorylation, SNVs, and disease associations.
