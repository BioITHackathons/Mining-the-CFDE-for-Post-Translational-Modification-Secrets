Data Sources & API Methods

GlyGen REST API

https://api.glygen.org — Swagger-documented, all endpoints use POST with JSON bodies. GlyGen aggregates data from multiple upstream databases into a unified MongoDB document store.

EndpointData ReturnedUpstream SourcesUsed In
POST /protein/detail/{ac}/ Full protein record: glycosylation sites, phosphorylation, SNVs, disease links, pathways, PTM annotations, sequence UniCarbKB UniProtKB iPTMnet BioMuta Protein Search
POST /protein/search_simple/ List ID for paginated results by accession, gene name, or keyword GlyGen index Protein Search (gene name resolution)
POST /protein/list/ Paginated protein list from a search; includes summary counts GlyGen index Protein Search (gene name resolution)
POST /disease/detail/{doid}/ Disease record: associated proteins (all species), glycans, biomarkers, children diseases Disease Ontology AGR Disease Explorer
POST /disease/search_simple/ Disease search by name/ID Disease Ontology Disease Explorer (name resolution)

UniProt REST API

https://rest.uniprot.org — RESTful, uses GET. Returns JSON with protein features, disease annotations, GO terms.

EndpointData ReturnedUpstream SourcesUsed In
GET /uniprotkb/{ac}.json Full UniProt entry: features (Modified residue, Glycosylation, Lipidation), disease comments, function, GO annotations UniProtKB (expert-curated + automatic annotation) Protein Search
GET /uniprotkb/search?query=gene_exact:... Protein accession resolution from gene name UniProtKB Protein Search (gene name resolution)

How This Dashboard Assembles Data

Protein Search mode: Fetches from both GlyGen (/protein/detail) and UniProt (/uniprotkb/{ac}.json) in parallel. GlyGen provides richer glycosylation data (site categories, GlyTouCan accessions, text mining), phosphorylation with kinase annotations (from iPTMnet), SNVs (from BioMuta), and pathways. UniProt provides broader PTM coverage (acetylation, ubiquitination, lipidation, etc.) and protein function text. The two sources are merged and deduplicated by position + PTM type, keeping the record with more evidence.

Disease Explorer mode: Fetches from GlyGen (/disease/detail/{doid}) to get all human proteins associated with a disease. Then batch-fetches /protein/detail/{ac} for the top N glycoproteins (3 concurrent requests). For each protein, computes glycosylation/phosphorylation counts, identifies SNVs within 3 residues of PTM sites, and flags disease-associated SNVs as high-impact candidates.

Gene name resolution: If the user enters a gene name instead of a UniProt accession, the tool first queries UniProt's search API (/uniprotkb/search?query=gene_exact:...). If that fails, it falls back to GlyGen's simple search (/protein/search_simple).
